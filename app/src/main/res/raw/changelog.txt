Jellyfin Music — Changelog

2.5.0
- Three song states: online, cached and downloaded
- Downloads tab switches between downloaded and cached songs
- Cached songs can be downloaded individually or all at once
- Playback menu shortened with dedicated sleep timer, speed and A-B dialogs
- More unit tests

2.4.2
- Fixed overlapping lyrics when increasing the font size

2.4.1
- Fixed a crash when rapidly toggling playback
- Keep the media service in the foreground for reliable background playback

2.4.0
- Equalizer with device presets and per-band adjustment
- Folder browsing for music libraries
- A-B repeat

2.3.0
- Desktop lyrics overlay (draggable, current and next line)
- Lyrics font size adjustment
- Lyrics offset adjustment in full-screen lyrics
- Lyrics offset and font size apply to the overlay

2.2.0
- Gapless and buffering tuning with stall recovery
- Notification and Bluetooth metadata with album art fallback
- Album artist and per-track artist shown correctly
- Multi-disc albums sorted and labelled by disc and track
- Download verification and repair
- Re-sync when leaving offline mode

2.1.0
- Auto-download favorites, playlists and recently added
- Persistent download queue with limited concurrency
- Manual and automatic offline mode with local-only browsing
- Paginated albums and artists with sorting
- Unit tests, GitHub Actions CI and optional keystore signing

2.0.0
- Sleep timer (15/30/60/90 minutes or end of track)
- Fade in/out with configurable duration
- Playback speed from 0.5x to 2x
- Theme styles: system, light, dark, dynamic color and AMOLED black
- Local playback position memory, no server dependency

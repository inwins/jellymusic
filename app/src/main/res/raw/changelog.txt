Jellyfin Music — Changelog

2.8.0
- Import a local music folder (SAF): scan songs with metadata and embedded cover art, play offline
- Local music is included in search
- On-device audio analysis: tempo, key, energy, loudness, brightness, vocal/instrumental estimate, beat strength
- "Similar sound" recommendations from analyzed tracks
- "Add to playlist" merged into the favorite button (long-press)
- Tap the artist or album on the Now Playing screen to search
- Search lists all songs first, then filters as you type
- Albums/artists: sort direction, random artists, favorites-only filter
- Auto-scroll to the currently playing track when opening a list
- Home shows only the first 6 favorites with "View all"; new "For you" recommendations that exclude favorites and frequently played songs
- Refresh server playlists after a manual sync

2.7.1
- Fix downloads not completing when using a custom download folder (SAF rename failure)
- Download failures now show an error instead of staying on the "cached" icon
- Clean up stale temporary download files on startup

2.7.0
- Offline mode (manual or automatic) shows only local downloads; no connection error or retry button
- New bottom navigation bar with icons
- Album/artist covers fill their cards, with rounded corners and a placeholder
- Floating rounded mini player
- Gradient background on the Now Playing screen
- Dynamic color enabled by default on Android 12+

2.6.3
- Manual offline mode no longer shows "cannot reach server" or a retry button
- Offline mode shows local downloads directly

2.6.2
- Clearer error when the server cannot create a playlist
- Sync error details shown in Settings

2.6.1
- Returning from a playlist keeps the Playlists tab selected
- System back navigates within the app instead of closing it
- Added sync buttons to the playlists tab and local playlist screen

2.6.0
- Screens render cached data instantly and refresh in the background
- In-memory response cache with longer TTLs for library data
- Home no longer waits for the connectivity check
- Fewer repeated server requests when switching screens

2.5.0
- Three song states: online, cached and downloaded
- Downloads tab switches between downloaded and cached songs
- Cached songs can be downloaded individually or all at once
- Playback menu shortened with dedicated sleep timer, speed and A-B dialogs
- More unit tests

2.2.0

Jellyfin Music — Changelog

2.27.3
- Offline mode now blocks API, download, image and prefetch requests at the network layer
- Lyrics fall back to the local .lrc file saved next to downloaded songs
- Playlists show only local playlists offline; server playlist pages show an offline hint

2.27.2
- Returning from album or artist pages now restores the previous scroll position in albums, artists, search, related artists and other lists

2.27.1
- Fixed the seek bar time labels overlapping the progress track; elapsed and remaining times now sit below the bar

2.27.0
- Package renamed to io.github.inwins.jellymusic for the public GitHub release
- This is a new app identity: the old com.example.jellymusic app is not upgraded and keeps its own data

2.26.14
- Deleting downloads now asks for confirmation: single songs, selected songs, the song menu, the now playing menu, and delete-all

2.26.13
- Faster Downloads tab: per-file sizes are cached in the background instead of queried on the main thread, so switching tabs no longer stutters
- Storage usage is read from the cache and updates as files are downloaded or deleted

2.26.12
- Folder multi-select: long-press or tap Select in the folder browser, choose several folders, then download them all (including subfolders)
- Queue, playlist and favorite actions ignore folders and apply to selected songs
- The local server address updates immediately in Settings after saving

2.26.11
- Two addresses for the same server: set a LAN address and the app uses it on Wi-Fi, falling back to the remote address automatically
- Add server form supports HTTP/HTTPS, host and port (defaults HTTP / 8096) with port validation
- Long-press any song to enter multi-select directly; the three-dot button still opens the song menu
- Downloads manager: sort by name/artist/album/size/recent, see per-song size, multi-select delete or delete all
- Lyrics are saved next to the downloaded audio (.lrc) and renamed or deleted along with the song
- Selection bar can now add to queue/playlist, download, favorite or delete downloads in bulk

2.26.10
- New Finamp-style slim seek bar with buffered progress, a small thumb and drag-anywhere seeking
- A floating time bubble appears while dragging; elapsed time on the left, remaining time on the right
- The mini player now uses a matching slim buffered progress line

2.26.9
- Batch download for folders: download every song in a folder and its subfolders from the folder browser
- Multi-select in every track list: long-press a song, choose Multi-select, then tap rows to select
- Batch actions: add to queue, add to playlist, download, favorite/unfavorite and delete downloads
- Select all in all songs, album/artist/playlist/local playlist, favorites, downloads, search, genres and offline lists
- Batch downloads are queued in a single pass so large folders download smoothly

2.26.8
- Downloads are now saved as "Artist - Title [ID].ext", so files are easy to recognize in the Music folder
- New "Rename downloads" action in Settings → Downloads to rename existing ID-named files
- The offline mode switch now sits at the top of Settings, right below the server address

2.26.7
- Full-screen visualizer with the system bars hidden; tap the screen to play or pause
- Six visualizer styles: bars, ring, ring + bars, waveform, mirrored spectrum and particles
- Lyrics pages now use the cover art as a slowly drifting blurred background
- A toast shows the visualizer style name when switching

2.26.6
- Artist songs are grouped by album with album headers, and can be sorted by album or by name
- Fixed the "Show all songs" button being hidden behind the mini player

2.26.5
- Artist songs: a "Collapse" button at both the top and the end when the full list is expanded

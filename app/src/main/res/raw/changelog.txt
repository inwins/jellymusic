Jellyfin Music — Changelog

2.17.3
- Melody/scale preview now uses a piano-like additive synth instead of a raw sine

2.17.2
- Analysis lists skip songs whose local file is missing
- Show melody confidence alongside the transcription

2.17.1
- Fix: "Save as playlist" from the queue no longer creates duplicate playlists
- Key/scale confidence now reports the in-key energy ratio (meaningful percentage)

- Tighter melody pitch range and voicing threshold

2.17.0
- Listening stats dashboard (library size, total plays, top artists/albums, recently played)
- Cover gestures: double-tap to play/pause, swipe up/down for next/previous
- Audio effects: bass boost, virtualizer and volume boost
- Related artists on the artist page

2.16.0
- Audio info card (codec, bitrate, sample rate, duration, size)
- Preload the next track into the playback cache
- Multi-select in All songs: add to queue/playlist or download in bulk

2.15.0
- Offline playback reports are queued and sent when the network returns
- Download pause/resume, storage usage and pending count
- Queue: search, shuffle remaining and save as playlist

2.14.0
- Instant mix / radio from any song (Jellyfin InstantMix)
- 0-5 star ratings and smart playlists (recently played / most played / favourites / high rated)
- Skip silence during playback
- Accent colour extracted from the album artwork

2.13.1
- Edit song metadata (title/artist/album) and cover art; for server songs the changes are written back to the Jellyfin server

2.13.0
- Feature library: browse analyzed songs and filter by BPM range or key
- Background analysis of downloaded & local songs (WorkManager)
- Multiple servers: save and switch between Jellyfin servers

- Instrumented UI test added to CI

2.12.0
- MFCC timbre embedding improves "similar sound" recommendations

- Quick Connect sign-in

2.11.0
- Chord progression recognition (major/minor triads per beat) and time-signature estimate
- Key confidence shown in the analysis
- Crossfade between tracks and loudness (ReplayGain) normalization
- Optional playback reporting to the Jellyfin server (scrobble + mark played)
- Visualizer styles (bars / ring / both), a full-screen visualizer page and key-coloured spectrum
- Per-song lyrics offset memory
- Albums/artists: favourite button and remembered sort/filter

2.10.0
- Automatic melody transcription: predominant-pitch tracking with median filtering and beat-grid quantisation
- Scale recognition (major/minor modes, church modes, pentatonic, blues) shown with its notes
- Piano-roll melody view and numbered notation (jianpu) with octave marks
- Improved key/scale matching and cleaner note segmentation

2.9.0
- Real-time spectrum visualizer on Now Playing: a radial ring around the cover plus spectrum bars, coloured by the song key
- Music theory: Camelot key wheel, relative key, diatonic chords and a 12-note chroma chart
- "Harmonic match" list and "build harmonic queue" based on Camelot distance and tempo compatibility

- Refresh server playlists after a manual sync
